### Технический радар

| Область          | Технология                       | Статус       | Что делаем                                  |
|------------------|----------------------------------|--------------|---------------------------------------------|
| **Хранилище**    | Data Lakehouse (S3 + Delta Lake) | Внедряем     | Новое основное хранилище вместо старого DWH |
| **Обработка**    | Apache Spark                     | Внедряем     | Для преобразования данных                   |
| **Оркестрация**  | Apache Airflow                   | Внедряем     | Для автоматизации пайплайнов                |
| **BI**           | Power BI                         | Внедряем     | Основной инструмент для отчетов             |
| **Каталог**      | Data Catalog                     | Пробуем      | Для поиска и описания данных                |
| **Безопасность** | RBAC/ABAC                        | Внедряем     | Разграничение прав доступа                  |
| **Шина данных**  | Apache Kafka                     | Пробуем      | Для обмена данными между системами          |
| **Легаси**       | SQL Server 2008                  | Замораживаем | Только как источник данных                  |
| **Легаси**       | Power Builder                    | Замораживаем | Постепенно убираем                          |

### Роадмап изменений

### Этап 1 (1-3 месяца) - Фундамент
- Настроить Data Lakehouse
- Запустить базовые пайплайны данных
- Настроить управление доступом
- Подключить первые домены (финансы, клиники)

### Этап 2 (4-6 месяцев) - Развитие
- Запустить портал самообслуживания
- Настроить каталог данных
- Перенести основные отчеты
- Подключить остальные домены

### Этап 3 (7-9 месяцев) - Оптимизация
- Настроить мониторинг качества данных
- Оптимизировать производительность
- Автоматизировать процессы

### Этап 4 (10-12 месяцев) - Завершение
- Полный перенос на новую платформу
- Отключение легаси-систем
- Обучение сотрудников

### Обоснование изменений

**Этап 1 - Фундамент**
- Нужно быстро создать новое хранилище, так как старое уже не справляется
- Без управления доступом нельзя работать с медицинскими и финансовыми данными
- Первые домены покажут ценность нового подхода

**Этап 2 - Развитие**
- Бизнесу нужны отчеты "вчера", поэтому запускаем портал
- Каталог данных поможет сотрудникам находить нужную информацию
- Постепенно подключаем все отделы компании

**Этап 3 - Оптимизация**
- Убеждаемся, что данные качественные и точные
- Ускоряем работу системы для пользователей
- Снижаем ручной труд через автоматизацию

**Этап 4 - Завершение**
- Полностью переходим на новую систему
- Экономим деньги на поддержке старых технологий
- Учим сотрудников работать эффективнее

**Преимущества для компании:**
- Отчеты готовятся в разы быстрее
- Новые бизнесы подключаются за недели вместо месяцев
- Данные защищены по современным стандартам
- Сотрудники могут сами строить аналитику
