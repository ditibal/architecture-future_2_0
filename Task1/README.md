## Проблемные места

1. **Устаревшее хранилище данных (DWH)**
    - Используется SQL Server 2008, который уже не поддерживается
    - Медленная работа отчетов (часы вместо минут)
    - Не справляется с большими объемами данных

2. **Все данные в одном месте**
    - Финансовые, медицинские и другие данные смешаны
    - Сложно управлять доступом к конфиденциальным данным
    - Любое изменение затрагивает всю систему

3. **Сложность добавления новых бизнесов**
    - Для подключения новых компаний нужно переделывать DWH
    - Долгая интеграция (месяцы вместо недель)

4. **Проблемы с безопасностью**
    - Нет четкого разграничения прав доступа
    - Риск утечки медицинских и финансовых данных

5. **Неудобство для пользователей**
    - Сотрудники не могут сами строить отчеты
    - Нет единого каталога данных
    - Зависимость от технических специалистов

6. **Высокая стоимость поддержки**
    - Большие затраты на поддержку старой системы
    - Ресурсы тратятся на "латание дыр" вместо развития

## Приоритизация (MoSCoW)

### Must (обязательно сделать в первую очередь)

- **Создать новое хранилище данных** на современных технологиях
- **Разделить данные по доменам** (финансы, медицина, ИИ)
- **Настроить управление доступом** к конфиденциальным данным
- **Запустить базовую версию портала** самообслуживания

### Should (важно сделать следующим этапом)

- **Настроить автоматическую передачу данных** из старых систем в новые
- **Создать каталог данных** для удобного поиска
- **Перенести основные отчеты** на новую платформу
- **Обучить сотрудников** работе с новыми инструментами

### Could (можно сделать при наличии ресурсов)

- **Добавить возможности для анализа в реальном времени**
- **Интегрировать дополнительные источники данных**
- **Улучшить интерфейс портала** самообслуживания

### Won't (не делать в этом году)

- **Полный отказ от всех старых систем** - будем переходить постепенно
- **Сложные функции искусственного интеллекта** - оставим на будущее
