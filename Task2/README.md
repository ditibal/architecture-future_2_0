## Домены

**1. Клиники (Hospital Operations)**
- Данные о работе медицинских учреждений
- Расписания врачей, графики приёмов
- Учёт медицинского оборудования
- Персонал клиник (без персональных данных)

**2. Финансы (Banking & Payments)**
- Банковские счета и операции
- Кредитные истории
- Платежи и транзакции
- Финансовая отчётность

**3. ИИ-сервисы (AI & Analytics)**
- Аналитические модели и прогнозы
- Обработка медицинских данных (обезличенных)
- Генерация бизнес-метрик
- Дашборды эффективности

**4. Поставщики (Supply Chain)**
- Данные от фармацевтических компаний
- Информация о поставках лекарств
- Учёт медицинского оборудования
- Логистика и запасы

**5. Клиенты (Customer Domain)**
- Общая информация о клиентах
- История взаимодействий с компанией
- Продуктовые профили
- Управление согласиями (consent)

**6. Платформа данных (Data Platform)**
- Центральное хранилище данных
- Портал самообслуживания
- Управление доступом
- Каталог данных и метаданные

## Аргументация разделения на домены

### Почему такое разделение логично:

**Соответствие бизнес-структуре**
- Каждый домен соответствует реальным подразделениям компании
- Команды работают с данными, которые сами создают
- Нет конфликта ответственности

**Естественные границы**
- Финансы, медицина, ИИ - это разные бизнес-процессы
- У каждого домена свои правила и требования
- Разные уровни безопасности данных

**Простота развития**
- Новый бизнес = новый домен
- Не нужно переделывать общее хранилище
- Можно развивать независимо

### Преимущества для компании:

**Быстрее внедряем новое**
- Добавляем фармацевтику - создаём домен "Поставщики"
- Не нужно ждать изменений в общем DWH
- Time-to-market сокращается с месяцев до недель

**Лучше контролируем данные**
- Каждый домен отвечает за качество своих данных
- Чёткие границы доступа
- Проще соблюдать правила (медицина, финансы)

**Экономия денег**
- Нет единого сложного хранилища
- Каждый домен масштабируется отдельно
- Меньше затрат на координацию изменений

**Безопасность**
- Медицинские данные отдельно от финансовых
- Чёткие правила доступа для каждого домена
- Риск утечки данных снижается

**Удобство для пользователей**
- Каждый сотрудник видит нужные ему данные
- Единый портал для всех отчётов
- Можно самому строить аналитику
